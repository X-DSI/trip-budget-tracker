# trip-budget-tracker

Plan a trip with other families, budget it, log expenses on the road, and split them fairly, even
with no signal.

- **Plan:** dates, destination, expected distance, cars, buses, trains and flights, who's coming.
- **Budget:** what the trip should cost, and each family's expected share.
- **Track:** log expenses offline. Split equally per family, per head, or dish by dish.
- **Settle:** see who owes whom, then pay with one tap over UPI.

Built as an offline-first PWA (React + Vite + Firebase) for phones and desktops.

This project follows the [agent-workflow](https://github.com/X-DSI/agent-workflow) protocol:
decisions are in [`docs/adr/`](docs/adr/), work orders in [`docs/handoff/`](docs/handoff/), and
current state in [`docs/STATUS.md`](docs/STATUS.md).
